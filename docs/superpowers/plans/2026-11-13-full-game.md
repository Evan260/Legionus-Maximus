# Legionus Maximus Full Game Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the prototype into the whole game in Features.md, with every feature coded and every feature whose art exists playable.

**Architecture:** All content (recruits, enemies, weapons, drills, provinces, commanders, upgrades, achievements) moves into `game/data/content.json`. The run stays plain data in `Sim`, now split into `Legion`, `Horde` and `Arms` helpers it owns; screens and the profile save are nodes around it. Content whose sprites are missing from the atlas is never spawned or offered, so adding art later turns it on with no code change.

**Tech Stack:** Godot 4.7.2, GDScript, GL Compatibility, GodotSteam, PixelLab art through `tools/art/`, Python 3 tools, GitHub Actions.

**Spec:** `Features.md` (what is in the game), `Plan.md` (why and the order). The prototype in `game/` is the starting point.

## Review Focus

- A level-up when every choice is maxed or locked: the run continues with no empty choice screen (Task 4 test `test_no_choices_left_skips_the_screen`).
- Content listed in content.json with no sprites in the atlas: never spawned, offered or shown in the camp (Task 2 test `test_content_without_art_is_hidden`).
- A profile file from an older version or a damaged one: the game starts with defaults and keeps the file's readable parts (Task 7 test `test_damaged_profile_loads_defaults`).
